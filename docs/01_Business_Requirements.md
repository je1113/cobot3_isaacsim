## 프로젝트 이름

> 프로젝트가 무엇인지 **한눈에 알 수 있는 이름**을 정합니다.

### 반도체 후공정 부품 캐리어 자동 이송·피킹 시스템 — 디지털 트윈 기반 사전 검증

패키징·테스트 라인의 트레이/매거진/카세트를 **이동 → 인식 → 파지 → 이송·배치 → 도킹/충전**까지 사람 개입 없이 처리하는 풀사이클을 시뮬레이션으로 검증

`스토커 이동` → `트레이 인식` → **`파지 (핵심)`** → `스테이션 이송·배치` → `도킹 / 충전`

| 구분 | 내용 |
|---|---|
| **대상 물체** | 웨이퍼(FOUP)가 **아니라**, 패키징·테스트 공정 사이를 오가는 **커스터머 트레이(C-tray), JEDEC 트레이, 매거진, 카세트** 등 완제품 이전 단계의 부품 운반체 |
| **작업 범위** | 스토커(적재소) 랙에서 트레이 인식 → 픽업 → 테스트 핸들러 / 패키징 스테이션으로 이송 → 배치 → 충전 스테이션 도킹까지의 **풀사이클** |
| **범위 밖** | 웨이퍼·FOUP 이송, 실물 장비 배포, 핸들러 내부 공정(테스트·몰딩 자체) |

## 1. 문제 정의 (Problem Definition)

> "현실에서 어떤 문제가 있는가?"를 서술합니다.
> 디지털 트윈 프로젝트이므로, 왜 실물이 아닌 시뮬레이션에서 먼저 검증해야 하는지도 함께 서술합니다.

### 1-1. 현실의 문제

반도체 후공정(패키징·테스트) 라인에서는 완제품 이전 단계의 부품이 **트레이·매거진·카세트**에 담겨 스토커(적재소)와 테스트 핸들러, 패키징 스테이션 사이를 반복적으로 오간다. 웨이퍼(FOUP) 이송은 이미 상당 부분 자동화되었지만, **트레이·매거진 레벨의 이송은 여전히 작업자가 손으로 랙에서 꺼내 카트에 싣고 장비까지 옮기는 수작업**에 의존하는 구간이 많다. 여기서 다음 문제가 발생한다.

| 문제 | 내용 |
|---|---|
| **① 오배송 · 혼입** | 트레이 로트(Lot) ID 착오, 랙 슬롯 착오, 목적지 장비 착오로 고가 부품이 잘못된 공정에 투입된다. 한 번 섞이면 추적성이 무너져 로트 전체를 재검사하거나 폐기해야 한다. |
| **② 오염 (Contamination)** | 사람의 손·의복·호흡은 파티클과 AMC(공중 분자 오염)의 접촉 경로다. SEMI 백서는 AMC가 클린룸 내 금속 부식을 유발해 스크랩(폐기)으로 이어질 수 있다고 명시한다. 사람이 트레이를 직접 만지는 횟수가 곧 오염 기회다. |
| **③ 처리량 변동 · 인력 의존** | 교대·피로에 따라 이송 속도와 실수율이 달라지고, 야간·휴일에는 라인 가동이 인력에 묶인다. 장비는 24시간 돌지만 자재 공급이 병목이 된다. |
| **④ 고객사 요구 = 납품 조건** | 삼성전자는 후공정 팹을 2030년까지 완전 무인화하는 것을 목표로, 장비 업체에 무인·자동화 기능 필수 탑재를 요구하고 있다. "자동화가 완료돼야 최종 납품 승인"이 나며, 그 대상이 풉 외에 **카세트·매거진·트레이**까지 확대되고 있다. |

→ 사람이 트레이를 옮기는 구간을 **이동·인식·파지·배치·도킹이 한 파이프라인으로 이어지는 자동 이송**으로 대체해야 한다. 이때 가장 실패하기 쉬운 단계는 **랙 안의 트레이를 정확히 인식하고 안정적으로 파지하는 것**이다.

### 1-2. 왜 시뮬레이션에서 먼저 검증해야 하는가

- **현장 테스트 비용이 극단적으로 높다.** 클린룸 라인은 정지 자체가 손실이고, 테스트 중 트레이 하나를 떨어뜨리면 그 위의 고가 부품 전체가 파손된다. 로봇을 실장비 옆에서 바로 시험하면 장비 충돌·라인 중단·오염 유입 위험을 동시에 떠안는다.
- **검증해야 할 조합이 너무 많다.** 트레이 종류(C-tray / JEDEC / 매거진), 랙 슬롯 높이, 트레이가 놓인 자세(치우침·기울어짐), 조명 변화, 장비 앞 정지 위치 오차 등 조합을 실물로 수백 회 반복하는 것은 비현실적이다. 시뮬레이션에서는 같은 조건을 무작위로 바꿔가며 반복 재현할 수 있다.
- **실패 케이스를 안전하게 재현할 수 있다.** 파지 실패, 낙하, 충돌 같은 시나리오를 물리 엔진 안에서 반복 관찰하고, 어느 조건에서 실패하는지 데이터로 남길 수 있다.
- **레이아웃·동선을 배포 전에 검토할 수 있다.** 스토커–통로–스테이션–충전 도킹 위치를 바꿔가며 이송 시간과 병목을 미리 비교할 수 있다.

→ 실물 배포 전에 디지털 트윈 환경에서 **로봇 동선, 트레이 인식 정확도, 파지 안정성, 목적지 매칭 로직**을 사전 검증하여 현장 도입 리스크를 최소화해야 한다.

### 1-3. 시장성 근거 — 왜 이 시나리오인가

| 근거 | 내용 |
|---|---|
| **[시장 규모]** 후공정 장비 시장이 크고 계속 성장 | 반도체 후공정 장비 시장은 **2025년 1,130억 달러 → 2030년 1,577억 달러**, CAGR 6.89% 성장 전망. IC 설계 복잡화와 소형 디바이스 수요 증가로 후공정 장비 수요가 구조적으로 늘어난다. 이 프로젝트가 다루는 도메인의 크기를 보여준다. |
| **[강제성]** "자동화 없으면 납품 불가"가 명문화 | 삼성전자는 후공정 팹 **2030년 완전 무인화**를 목표로 장비 업체에 무인·자동화 기능 필수 탑재를 요구. "시제품을 개발해도 자동화가 완료돼야 최종 납품 승인"이라는 수준의 강제성이 있으며, 자동화 대상이 풉 외에 **카세트·매거진·트레이**까지 확대되고 있다. 본 시나리오의 범위와 정확히 일치한다. |
| **[손실 직결]** 오염은 추상적 리스크가 아니다 | SEMI 백서: AMC(공중 분자 오염)는 클린룸에서 **금속 부식을 유발하고 웨이퍼 스크랩으로 이어질 수 있다**. 사람 손이 트레이·부품을 직접 옮기는 과정은 오염원 접촉 기회를 늘리며, 이를 로봇 이송으로 대체하는 것이 **고가 부품 오배송·오염 방지** 니즈와 맞닿는다. |

## 2. 프로젝트 목표 (Project Goal)

> "이 프로젝트가 완료되면 무엇이 달라지는가?"를 서술합니다.
> 측정 가능한 기준을 포함하되, 구현 방법(YOLO, ROS2 등)은 쓰지 않습니다.

1. **풀사이클 자동 이송을 시뮬레이션에서 재현한다.** 스토커 랙에 놓인 트레이를 인식하고 픽업한 뒤, 테스트 핸들러/패키징 스테이션까지 이송해 배치하고, 마지막에 충전 스테이션에 도킹하기까지를 **사람 개입 없이 하나의 파이프라인**으로 수행한다.
2. **핵심 파지 단계를 반복 검증해 성공률을 정량화한다.** 트레이 종류(C-tray / JEDEC / 매거진)와 랙 슬롯 위치, 트레이가 놓인 자세(치우침·기울어짐)를 무작위로 바꿔도 인식과 파지가 정상 동작하는지 반복 검증하고, 조건별 성공률과 실패 유형을 기록한다.
3. **오배송 0건을 검증한다.** 트레이 ID(로트)와 목적지 스테이션을 매칭해, 잘못된 스테이션에 배치되는 경우가 반복 시험 중 한 번도 발생하지 않음을 확인한다.
4. **사람 접촉 0회를 달성한다.** 이송 구간 전체에서 작업자가 트레이를 만지는 단계가 없음을 파이프라인 정의로 보장한다(오염 기회 제거의 대리 지표).
5. **현장 배포 시 예상 성능과 한계를 사전에 파악한다.** 시뮬레이션 결과로 예상 성공률, 1회 이송 사이클 타임, 실패가 집중되는 조건(특정 트레이·슬롯 높이·자세)을 정리해 실제 도입 시 필요한 보완점을 도출한다.

### 측정 가능한 성공 기준 (초안)

> ※ 수치는 팀 합의 후 확정. 반복 시행 횟수 N은 조건 조합(트레이 3종 × 슬롯 위치 × 자세 변화)을 커버할 수 있도록 설정.

| 지표 | 목표 (초안) | 측정 방법 |
|---|---|---|
| 풀사이클 무개입 완료율 | ≥ 90 % (N회 반복) | 시작~도킹 완료까지 사람 개입·수동 재시도 없이 종료된 시행의 비율 |
| 트레이 인식 정확도 | ≥ 95 % | 트레이 종류·위치를 정답과 비교해 허용 오차 이내로 산출한 비율 |
| **파지 성공률 (핵심)** | ≥ 90 % (조건별 집계) | 파지 후 리프트·이송 중 낙하·미끄러짐 없이 배치까지 유지된 비율, 트레이 종류·자세별로 분리 집계 |
| 오배송 건수 | 0 건 | 배치된 스테이션과 트레이 ID의 목적지 매칭 검사 |
| 낙하 · 충돌 건수 | 0 건 | 물리 시뮬레이션 상 트레이 낙하, 랙·장비와의 충돌 이벤트 로그 |
| 사람 접촉 횟수 | 0 회 | 파이프라인 단계 정의상 수동 개입 단계 부재 |
| 1회 이송 사이클 타임 | 기록 · 비교 | 스토커 출발~스테이션 배치 완료 시간, 레이아웃/조건별 비교 (목표치는 검증 후 설정) |

### 완료 후 달라지는 것

| Before | After |
|---|---|
| 트레이 이송이 사람 손에 의존해 오배송·오염·처리량 변동이 상존하고, 자동화 검증은 실장비에서만 가능하다. | 이동→인식→파지→배치→도킹 풀사이클이 시뮬레이션에서 검증된 상태로 존재하며, 어떤 조건에서 얼마나 성공하는지 수치로 말할 수 있다. 실물 도입 시 무엇을 보완해야 하는지가 근거와 함께 정리된다. |

## 3. 비즈니스 요구사항 목록 (Business Requirements)

> 고객·운영사 관점에서 "시스템이 무엇을 해결해야 하는가"를 요구사항 단위로 정리합니다.
> 구현 방법과 시스템 내부 지표(인식 정확도, 파지 성공률 등)는 System Requirements에서 다룹니다.

### 비즈니스 목표 (한 줄)

후공정 라인의 트레이·매거진·카세트 이송을 **사람 없이** 수행해 오배송·오염·인력 의존을 없애고, 고객사의 **무인화 납품 요건**을 충족한다. 실물 투입 전에 **시뮬레이션으로 검증**한다.

### 이해관계자와 기대

| 이해관계자 | 기대하는 것 |
|---|---|
| 후공정 팹 운영사 (고객사) | 2030년 무인화 달성, 오염·오배송으로 인한 로트 손실 제거 |
| 장비·자동화 공급사 (우리) | 자동화 기능이 검증되어야 납품 승인이 나므로, 검증된 이송 자동화 기능 확보 |
| 생산 관리자 | 야간·휴일 포함 일정한 자재 공급, 로트 추적성 유지 |
| 품질 · 오염 관리 담당 | 사람 접촉에 의한 오염 경로 제거 |
| 현장 작업자 | 반복 운반 작업에서 벗어남, 무거운 매거진·카세트 취급 안전 |

### 요구사항 목록

| ID | 요구사항 | 근거 | 충족 판단 기준 | 우선순위 |
|---|---|---|---|---|
| **BR-01** | 스토커 ↔ 장비 간 캐리어 이송 **전 구간에 사람이 개입하지 않아야 한다** | 삼성전자 2030 후공정 무인화, "자동화 완료돼야 최종 납품 승인" | 이동·인식·파지·배치·도킹 전 단계에서 수동 개입 0 | Must |
| **BR-02** | 캐리어는 **항상 지정된 목적지 장비에만** 도착해야 하며 로트 추적이 유지되어야 한다 | 혼입 1건이 로트 전체 재검사·폐기로 이어짐 | 오배송 0건, 캐리어 ID ↔ 목적지 이력 100% 기록 | Must |

| **BR-04** | 이송 중 **낙하·충돌로 인한 부품 손상이 없어야 한다** | 트레이 1개에 고가 부품 다수, 낙하 시 전량 손실 | 낙하·충돌 0건 | Must |
| **BR-05** | C-tray, JEDEC 트레이, 매거진, 카세트 등 **서로 다른 캐리어를 하나의 시스템으로** 처리해야 한다 | 고객사 자동화 대상이 풉 외 카세트·매거진·트레이로 확대 | 최소 3종 캐리어 처리 | Must |
| **BR-06** | 교대·피로·야간 여부와 무관하게 **일정한 이송 처리량**을 유지해야 한다 | 장비는 24시간 가동되나 자재 공급이 인력에 묶여 병목 | 사이클 타임이 기준 편차 이내, 연속 가동 가능 | Should |
| **BR-07** | 실물 투입 전에 **시뮬레이션으로 성공률과 한계를 확인**해 도입 리스크를 줄여야 한다 | 클린룸 현장 테스트는 라인 정지·부품 파손·오염 유입 위험 | 조건별 성공률·실패 유형·사이클 타임 리포트 산출 | Must |
| **BR-08** | 검증 결과가 **고객사 납품 승인 근거**로 쓰일 수 있어야 한다 | 자동화 검증 없이는 납품 불가 | 재현 가능한 검증 절차와 결과 문서 | Should |
| **BR-09** | 기존 스토커·장비 **레이아웃을 크게 바꾸지 않고** 적용 가능해야 한다 | 라인 개조 비용과 정지 시간 최소화 | 기존 레이아웃에서 동작, 변경이 필요하면 사전에 식별 | Could |

### 제약 · 가정

- 대상은 완제품 이전 단계의 캐리어(트레이·매거진·카세트)이며 웨이퍼·FOUP는 제외한다.
- 실물 배포는 범위 밖이다. 이번 프로젝트의 산출물은 **시뮬레이션 검증 결과와 리포트**다.
- 시장·고객사 요구 근거는 제공된 자료(후공정 장비 시장 전망, 삼성전자 무인화 요구, SEMI AMC 백서) 기준이다.
